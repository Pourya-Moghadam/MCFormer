# Paper artifact tools

Executable repository wrappers live in `../scripts`; reusable implementations live in
`../src/mcformer`. `scripts/analyze.py` generates E02--E05 statistics, tables, and figures from
machine-readable prediction artifacts. E06--E12 sweep/corruption tools and E13--E16 benchmark,
cost, attention, and feature-projection tools follow the same rule and never embed manuscript
result values.
